# Machine Translation NLP Project

This repository collects notebook-based experiments for machine translation using multiple deep learning approaches. It is structured as an academic and portfolio project that compares classic sequence models with transformer-based methods.

## Included Approaches
- RNN-based machine translation in RNN-machine-translation.ipynb
- Transformer model built from scratch in machine_translation_transformers_scratch.ipynb
- Pretrained GPT-2 based experimentation in Pretrained_Transformer_Model_Use_GPT_2_(1) (1).ipynb

## Repository Contents
- NLP Project Report.pdf - project write-up
- spa.txt - dataset file used in experiments
- Jupyter notebooks for model training and experimentation

## Tech Stack
- Python
- Jupyter Notebook
- Deep learning for NLP
- Transformer and sequence modeling concepts

## How to Run
1. Create a Python environment.
2. Install the notebook dependencies used in each experiment.
3. Launch Jupyter Notebook or JupyterLab.
4. Open the notebook you want to explore and run the cells in order.

## Notes
- This repository is best viewed as an experimentation and learning project.
